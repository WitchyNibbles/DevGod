# Devgod Docs Research

Use this skill for documentation lookup, API verification, release-note checks, and standards questions.

## Goal

Return current, source-backed findings that are safe to use in planning or implementation.

## Workflow

1. Define the concrete question and what would count as an answer.
2. Prefer, in order:
   - official docs
   - release notes or changelogs
   - primary specs or maintainer sources
3. Record version or date context when it matters.
4. Separate:
   - sourced fact
   - inference
   - unresolved ambiguity
5. If local repo context matters, read the repo evidence before or alongside external docs.

## Rules

- no blog-first answers when primary docs exist
- do not assume stale behavior is still current
- cite the source used

## Output

Return concise findings with sources, dates or versions, and any unresolved drift risk.
